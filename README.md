# MDM-TAE-1 Quiz Website

## About the Project

This project is an **online quiz website** designed to provide users with a simple and interactive way to test their knowledge.

The website presents quiz questions with multiple-choice answers. Users can select an answer for each question and complete the quiz to check their performance.

## What Does the Website Contain?

The website contains:

* A quiz interface
* Multiple-choice questions
* Multiple answer options for each question
* A question navigation system
* An option to submit the quiz
* A final result/score
* A simple and user-friendly design

## How Does the Quiz Work?

The quiz works in the following way:

1. The user opens the quiz website.
2. Quiz questions are displayed on the screen.
3. Each question has multiple answer options.
4. The user selects the answer they think is correct.
5. The user continues through the questions.
6. After answering the questions, the user submits the quiz.
7. The website checks the selected answers.
8. The final score/result is displayed to the user.

## Purpose of the Project

The main purpose of this project is to create an interactive quiz application while learning the basics of web development.

It demonstrates how a website can:

* Display information dynamically
* Accept user input
* Handle user interactions
* Check answers
* Calculate a score
* Display results

## Technologies Used

* **HTML** – Used to create the structure of the website.
* **TailWind CSS** – Used for the design, layout, colors, and styling.
* **JavaScript** – Used to handle quiz logic, user selections, answer checking, and score calculation.

## User Experience

The quiz is designed to be simple and easy to use. The user does not need any technical knowledge to take the quiz. They simply read each question, select an answer, and submit the quiz to see their result.
